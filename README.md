One line about working beside an AI coding agent, told from the stage
of a live demo:

> My AI agent wrote the demo, ran it live, and when it crashed it fixed itself before I could say 'but it worked in rehearsal.'

The joke is built for the judge's brief: on subject (an AI that writes
code, during a demo), a surprise at the very end (the agent beats the
presenter to the classic excuse by fixing the crash first), true to
every developer who has demoed live, one line with nothing explained,
and a fresh angle on the oldest demo excuse there is.

`main.py` (Python 3.13, standard library only) writes the joke to
`/output/entry.txt`. Run it locally with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Two runs write byte-identical output. The file is 125 Unicode
characters — inside the 1–280 gate — one line, no trailing newline.
